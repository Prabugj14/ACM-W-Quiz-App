# 🎯 ACM-W Recruitment Task: Interactive Quiz App

### 🌐 [Click Here to Play the Live Quiz App!](https://prabugj14.github.io/ACM-W-Quiz-App/)

## 📖 Project Overview
This is a single-page interactive Quiz Web Application built for the **ACM-W 2026 Recruitment Challenge**. The app tests users on general knowledge about the Association for Computing Machinery (ACM-W) and fundamental concepts in Artificial Intelligence (AI). 

It features a smooth, dynamic user interface with instant feedback, accurate scoring, and a fully responsive design.

## ✨ Key Features
- **Interactive Quiz Flow:** Seamless single-page experience without reloading.
- **10+ Multiple Choice Questions:** Carefully curated questions covering ACM history and Basic AI concepts.
- **Real-time Progress Tracking:** Visual progress bar and question counter.
- **Instant Feedback:** Immediate visual cues (green/red) for correct and incorrect answers.
- **Detailed Results:** Final score breakdown with a review of correct/incorrect answers.
- **Responsive UI/UX:** Clean, modern design that works perfectly on both desktop and mobile devices.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (Custom styling with animations), Vanilla JavaScript
- **Deployment:** GitHub Pages
